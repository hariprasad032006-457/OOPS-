## 📌 About This Repository

This repository contains small Python programs and practice examples. Files are grouped by topic so each concept is easy to find, run, and revise.

## 📚 Topics

| Topic | What you'll find |
|---|---|
| Classes & objects | Constructor, instance attributes, methods |
| Functions | Return values, dictionaries, updating records |
| `*args` and `**kwargs` | Flexible positional and keyword arguments |
| Built-in functions | Example of `all()` |

## ▶️ Run the examples

Make sure Python 3 is installed. Run commands from the repository root:

```bash
python 01_classes_objects/library_class.py
python 02_functions_arguments/employee_salary.py
python 02_functions_arguments/args_kwargs.py
python 03_builtins/all_function.py
```

### Gemini API example

Install the SDK:

```bash
pip install google-genai
```

Set the API key in an environment variable instead of writing it into the source code.

**PowerShell**
```powershell
$env:GOOGLE_API_KEY="your-api-key"
python 04_ai_api/gemini_api_example.py
```

> 🔐 Never commit API keys or other secrets to GitHub.
